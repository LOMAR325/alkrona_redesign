# Lumen Botanica

A dark-mode, "biophilic sci-fi" storefront for a plant nursery — deep greenhouse
greens, neon glow accents, frosted-glass UI and scroll-driven motion.

Static HTML, CSS and vanilla JS. No build step, no dependencies, no framework.

```bash
python3 serve.py
```

Then open <http://127.0.0.1:4173>. (Opening `index.html` directly from the file
system works too — everything is same-origin and dependency-free.)

---

## What's here

```
index.html          Home: hero, collections, catalog preview, method, about,
                    guides, reviews, newsletter + contact, footer
shop.html           Full catalog with search, filters, sort
checkout.html       Cart review, delivery form, demo order confirmation
assets/css/         One stylesheet — design tokens at the top
assets/js/          data.js · cart.js · shop.js · checkout.js · app.js
assets/img/         26 generated SVG botanicals + scene art
tools/              Art generator and header/footer sync script
serve.py            Tiny static server for local preview
```

### JavaScript modules

| File | Responsibility |
| --- | --- |
| `data.js` | The catalog (24 plants), collections, guides, reviews, method steps. **Edit content here.** |
| `cart.js` | Cart state in `localStorage`, the slide-over drawer, toasts, money formatting |
| `shop.js` | Catalog search / filter / sort, URL sync (`?cat=`, `?q=`, `?sort=`) |
| `checkout.js` | Order summary, demo order placement |
| `app.js` | Header, scroll choreography, carousel, particles, forms, card templates |

Scripts are plain `<script defer>` — load order is `data → cart → shop → checkout → app`.

## Design tokens

Everything visual is driven by custom properties at the top of
`assets/css/styles.css`:

| Token | Value | Used for |
| --- | --- | --- |
| `--bg` | `#04070a` | Page ground |
| `--lime` | `#b8ff3c` | Primary CTA, prices, active states |
| `--mint` | `#7cffc4` | Links, eyebrows, glow borders |
| `--teal` | `#2ae0d0` | Gradient mid-tone |
| `--violet` | `#9b7cff` | Rare / accent category |
| `--rose` | `#ff9ecb` | Sale badges, wishlist |
| `--text` / `--muted` / `--dim` | `#e9f5ef` / `#93a9a1` / `#6d817b` | Type ramp |

`--muted` is 8:1 against the page ground and `--dim` is 4.9:1, so body and
caption text both clear WCAG AA on the dark theme.

Type: **Space Grotesk** for headings, **Inter** for body, loaded from Google
Fonts with full system fallbacks. To self-host, drop the two `<link>` tags and
point `--font-display` / `--font-body` at your own `@font-face` rules.

## Scroll & motion

| Effect | Where |
| --- | --- |
| Glowing progress bar | `.progress`, driven by `progress()` in `app.js` |
| Staggered fade-up reveals | `.reveal` + `IntersectionObserver`; stagger via `data-stagger="80"` on a parent, or `--d` per element |
| Parallax | `data-par="0.05"` on any element (value = strength) |
| Pinned "method" section | `#method[data-pin]` — a 340vh track with a sticky panel; steps and images cross-fade with scroll progress |
| Counting stats | `data-count="520" data-suf="+"` (also `data-pre`, `data-dec`) |
| Hero particles | `<canvas id="particles">`, DPR-aware, pauses off-screen and on tab blur |
| Pointer spotlight | `.spot` / cards — JS writes `--mx` / `--my`, CSS paints a radial highlight |
| Auto-advancing reviews | Dots, arrows, arrow keys, swipe; pauses on hover and focus |

All of it is disabled or flattened under `prefers-reduced-motion: reduce`, and
the palette firms up under `prefers-contrast: more`.

## Commerce

Cart state lives in `localStorage` under `lb.cart.v1` and syncs across tabs.
Free shipping over €75, otherwise €6.95 — both constants sit at the top of
`cart.js`, alongside the currency (`LB.currency` in `data.js`).

**Checkout is a front-end demo.** No payment provider is wired up and no card
details are collected anywhere; placing an order clears the cart and shows a
confirmation with a generated reference. To go live, mount your Stripe / Mollie /
Adyen element inside the payment card in `checkout.html` and submit the order in
the `form:valid` handler in `checkout.js`.

## Imagery

There is no stock photography here. All 26 images are SVGs generated by
`tools/generate-art.py` — 24 species drawn from parametric archetypes
(fenestrated aroid, rosette, frond, trailing vine, cane, canopy, spike…), plus
collection scenes, guide cards and the hero specimen. They're a few kilobytes
each, resolution-independent, and share one colour grade.

```bash
python3 tools/generate-art.py     # rewrites assets/img/
```

To swap in real photography, replace the files and update the `img` paths in
`data.js` (products build theirs from `id`, so either keep the
`plant-<id>.svg` naming or set `p.img` explicitly).

## Editing

- **Add a plant** — append an object to `LB.products` in `data.js` and drop
  `assets/img/plant-<id>.svg` next to the others. Cards, filters, search,
  counts and the cart all pick it up automatically.
- **Change the nav or footer** — edit `index.html`, then run
  `python3 tools/sync-chrome.py` to copy the chrome into the sub-pages
  (their `<main>` content is left alone).
- **Rename the business** — search for `Lumen Botanica` across the three HTML
  files and `README.md`; the logo mark is inline SVG in the header and footer.

## Browser support

Evergreen Chrome, Edge, Firefox and Safari. Uses `IntersectionObserver`,
`backdrop-filter`, CSS custom properties, `clamp()` and `aspect-ratio` — all
gracefully degrading (the site remains fully readable and shoppable if
`backdrop-filter` or `IntersectionObserver` are unavailable).
